## Modifica di schema proposta per C (non fatta)
Un solo campo sulla tabella `franchise`: `kind TEXT CHECK (kind IN ('film_series','list','media_franchise','collection','other'))`, vuoto se Wikidata non dà una classe riconosciuta (nessun valore inventato), con la classe Wikidata di origine in `source_ref`. Migrazione verificabile: nuova colonna nullable, nessuna riga esistente cambia; `schema.html`, `schema.mmd` e `approved_views.py` si rigenerano con `generate`; la build resta riproducibile; la vista `v_franchise` espone `kind`; il tool dice «elenco» quando `kind = 'list'` invece della nota generica. Senza schema, l'alternativa è non importare i franchise di classe «elenco» (si perderebbero le appartenenze legittime come «list of Tom and Jerry feature films»): sconsigliata.
